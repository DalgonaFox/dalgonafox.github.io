# Yale School of Art
Esse repositório contém um redesign de uma página da web para fins de aprendizado! Apenas a página inicial foi refeita, e isso foi um trabalho em dupla feito durante o Técnico em Desenvolvimento de Sistemas no SENAI.
> A página que eu refiz é a da Escola de Artes de Yale, que você pode encontrar [aqui.](https://www.art.yale.edu/)
> Você pode visualizar esse projeto no ar [aqui,](https://dalgonafox.github.io/websites/redesign/yale/index.html) e ver o protótipo do Figma [aqui.](https://www.figma.com/design/2DZKpDkbzigUH5hrdlqObq/Yale-University-of-Art?node-id=0-1&t=1a2CaB9zd8IC4Aur-1)
