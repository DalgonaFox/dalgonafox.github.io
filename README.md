# dalgonafox.github.io
Esse repositório contém todos os exercícios desenvolvidos por mim durante o Técnico em Desenvolvimento de Sistemas.
> Eu utilizo esse repositório como uma forma de hospedar sites estáticos. Se você quer ver algo que eu fiz que está aqui dentro, basta digitar "https://dalgonafox.github.io/[insira caminho desejado aqui]".
> Por exemplo, o link "https://dalgonafox.github.io/front-end/htmlcss/primeirohtml/" irá te direcionar ao primeiro arquivo em HTML que eu já fiz na vida, e ele está dentro desse repositório.
> Isso não vai funcionar com projetos node.js ou com bancos de dados, já que é necessário hospedar em algum lugar.
